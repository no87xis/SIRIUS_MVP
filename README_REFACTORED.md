# Sirius Group - Система управления складом (Рефакторинг)

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Инициализация базы данных
```bash
python init_db.py
```

### 3. Запуск сервера
```bash
python run_server.py
```

Или альтернативно:
```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 🗄️ База данных

По умолчанию используется SQLite (`sirius.db`). Для продакшена рекомендуется PostgreSQL.

### Переключение на PostgreSQL:
1. Установите PostgreSQL
2. Создайте базу данных
3. Измените `DATABASE_URL` в `.env` файле:
   ```
   DATABASE_URL=postgresql://user:password@localhost/sirius_db
   ```

## 🐛 Устранение проблем

### Ошибка импорта модулей:
```bash
# Убедитесь, что находитесь в корневой папке проекта
cd Sirius_sklad_new-master
python run_server.py
```

### Ошибка базы данных:
```bash
# Пересоздайте БД
rm sirius.db
python init_db.py
```

### Ошибка порта занят:
```bash
# Измените порт в run_server.py или убейте процесс
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```
