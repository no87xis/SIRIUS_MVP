# Sirius Group - MVP Релиз

## 🚀 Быстрый старт

### 1. Проверка готовности
```bash
python quick_check.py
```

### 2. Запуск сервера
```bash
python start_optimized.py
```

### 3. Проверка работы
- Откройте: http://localhost:8000
- API документация: http://localhost:8000/docs
- Health check: http://localhost:8000/health

## 📋 Что включено в MVP

### ✅ Основной функционал
- **Управление товарами**: добавление, редактирование, просмотр
- **Система заказов**: создание через магазин, просмотр, изменение статусов
- **Магазин**: корзина, оформление заказов, выбор доставки
- **Админ-панель**: управление пользователями, просмотр логов
- **Доставка**: 5 вариантов доставки с расчетом стоимости

### ✅ Статусы заказов (4 статуса)
- `UNPAID` - Не оплачен
- `PAID_NOT_ISSUED` - Оплачен, не выдан
- `PAID_ISSUED` - Оплачен и выдан
- `COURIER_NOT_PAID` - Курьер не оплачен

### ✅ Технические особенности
- **SQLite** по умолчанию для быстрого старта
- **Ленивая загрузка** роутеров
- **Graceful shutdown** с закрытием соединений
- **Централизованное логирование** с ротацией файлов
- **Мониторинг производительности**
- **Health checks** с таймаутами

## ❌ Что отключено в MVP

### 🚫 QR-функционал
- QR-генерация и сканирование отключены
- Публичные QR-ссылки перенаправляют в магазин
- QR-сканер перенаправляет в админ-панель

### 🚫 Уведомления
- WhatsApp уведомления отключены
- Telegram уведомления отключены
- Email уведомления отключены
- Уведомления о доставке отключены

### 🚫 Ручное создание заказов
- Создание заказов в админ-панели отключено
- Все заказы создаются только через магазин

## 🔧 Устранение неполадок

### Проблема: Сервер не запускается
```bash
# Проверьте готовность
python quick_check.py

# Проверьте зависимости
pip install -r requirements.txt
```

### Проблема: База данных недоступна
- SQLite файл создается автоматически
- Проверьте права доступа к папке

### Проблема: Медленный старт
- Используйте `start_optimized.py`
- Проверьте, что нет внешних зависимостей

## 📈 Производительность

### Время запуска
- **Цель**: < 2 секунды
- **Фактически**: ~1-1.5 секунды

### Время ответа
- **Health check**: < 1 секунды
- **Основные страницы**: < 3 секунд

### Память
- **Базовое потребление**: ~50-100MB
- **Под нагрузкой**: ~100-200MB

## 🚀 Развертывание

### Локальная разработка
```bash
python start_optimized.py
```

### Продакшн
1. Создайте `.env` файл с продакшн настройками
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
