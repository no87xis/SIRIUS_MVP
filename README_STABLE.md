## 🚨 Troubleshooting

### Проблемы запуска
1. **Проверьте готовность**: `python quick_check.py`
2. **Проверьте зависимости**: `pip install -r requirements.txt`
3. **Проверьте права доступа**: убедитесь, что есть права на запись в папку

### Проблемы производительности
1. **Проверьте health-check**: `curl http://127.0.0.1:8000/health`
2. **Проверьте логи**: `tail -f logs/sirius_*.log`
3. **Проверьте мониторинг**: `/admin/metrics`

### Проблемы с БД
1. **Проверьте подключение**: `python -c "from app.db import engine; print(engine.connect())"`
2. **Пересоздайте БД**: удалите `sirius.db` и перезапустите
3. **Проверьте права**: убедитесь в правах на запись
