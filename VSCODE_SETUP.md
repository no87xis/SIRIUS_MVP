# ⚙️ Настройка VS Code для автозапуска

## 📦 Рекомендуемые расширения

Установите следующие расширения для оптимальной работы:

### Обязательные:
1. **Python** (ms-python.python) - поддержка Python
2. **Code Runner** (formulahendry.code-runner) - автозапуск кода
3. **Live Server** (ritwickdey.liveserver) - автоперезагрузка HTML

### Дополнительные:
4. **Flake8** (ms-python.flake8) - линтер Python
5. **Pylint** (ms-python.pylint) - анализатор кода
6. **PowerShell** (ms-vscode.powershell) - поддержка PowerShell

## 🚀 Автозапуск кода

### Настройки уже созданы в `.vscode/settings.json`:
- ✅ Автозапуск при сохранении файла
- ✅ Запуск в терминале
- ✅ Автосохранение с задержкой 1 сек
- ✅ Форматирование при сохранении

### Тестирование:
1. Откройте файл `test.py`
2. Сохраните файл (Ctrl+S)
3. Код должен автоматически запуститься в терминале

## 🔄 Автоперезапуск сервера

### Вариант 1: С watchfiles (рекомендуется)
```bash
# Установка зависимости
pip install watchfiles

# Запуск с автоперезапуском
python start_with_watch.py
```

### Вариант 2: Через VS Code
1. Нажмите `Ctrl+Shift+P`
2. Выберите "Tasks: Run Task"
3. Выберите "Start FastAPI with Watch"

## 📋 Горячие клавиши

- `Ctrl+S` - Сохранить и запустить код
- `Ctrl+Shift+P` - Командная палитра
- `F5` - Запуск отладки
- `Ctrl+Shift+`` - Новый терминал

## 🛠️ Задачи VS Code

Доступные задачи (Ctrl+Shift+P → Tasks: Run Task):
- **Start FastAPI Server** - обычный запуск
- **Start FastAPI with Watch** - с автоперезапуском
- **Run Tests** - запуск тестов
- **Quick Check** - быстрая проверка

## 🌐 Live Server для HTML

Для автоперезагрузки HTML страниц:
1. Установите расширение "Live Server"
2. Откройте HTML файл
3. Правый клик → "Open with Live Server"
4. Страница будет автоматически перезагружаться при сохранении

## 🔧 Отладка

Для отладки FastAPI:
1. Нажмите `F5`
2. Выберите "FastAPI Development Server"
3. Установите точки останова в коде
4. Сервер запустится в режиме отладки

## ⚡ Быстрый старт

1. Откройте проект в VS Code
2. Установите рекомендуемые расширения
3. Откройте `test.py` и сохраните (Ctrl+S)
4. Убедитесь, что код запустился автоматически
5. Запустите сервер: `python start_with_watch.py`

## 🎯 Готово!

Теперь ваш код будет автоматически запускаться при сохранении файлов! 🚀
